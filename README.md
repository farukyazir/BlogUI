# 📝 BlogUI – Modern Blog Website

A responsive and modern **Blog UI** built with **React.js and Vite** 🚀

BlogUI is designed to provide a clean and simple reading experience where users can explore blogs based on different technology domains such as **Full Stack Development, Data Science, Cyber Security, and AI**.

---

## 🌐 Live Demo

🚀 **Live Website:**
https://blggui.netlify.app/

💻 **GitHub Repository:**
https://github.com/farukyazir/BlogUI

---

## ✨ Features

* 🏠 **All Blogs** – View all available blog posts
* 💻 **Full Stack Development** – Explore full-stack related articles
* 📊 **Data Science** – Browse data science content
* 🔐 **Cyber Security** – Explore cybersecurity topics
* 🤖 **Artificial Intelligence** – Read AI-related blogs
* 🔎 **Search Bar** – Search interface for blog content
* 📱 **Responsive Design** – Works across desktop and mobile screens
* 📂 **Blog Details** – Open individual blog posts
* 🧭 **React Router Navigation** – Navigate between different blog categories
* 📱 **Mobile Menu** – Three-dot menu for smaller screen sizes
* 🎨 **Clean UI** – Simple and modern blog interface
* 📌 **Sticky Header** – Header stays visible while scrolling
* 🌑 **Scroll Shadow** – Header shadow appears while scrolling

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/farukyazir/BlogUI.git
```

### 2️⃣ Open the Project

```bash
cd BlogUI
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

The application will run locally using the Vite development server.

---

## 🧩 Main Components

### 🏠 Header

The header contains:

* Logo
* Blog title
* Search bar
* Sign-in section
* Sticky positioning
* Scroll shadow effect

### 🧭 Navbar

The navigation bar provides access to different blog categories:

```text
All
Full Stack Development
Data Science
Cyber Security
AI
```

On smaller screens, the categories are available through a **three-dot mobile menu**.

### 📰 BlogCard

The `Blogcard` component displays individual blog information such as:

* 🖼️ Blog image
* 📝 Blog title
* 🏷️ Blog domain
* 📖 Blog content

### 📖 Blog Details

Users can select a blog card and navigate to its individual blog page.

---

## 📱 Responsive Design

BlogUI is designed to adapt to different screen sizes.

### 💻 Desktop

The full navigation menu is displayed.

### 📱 Mobile

The navigation changes to a compact three-dot menu:

```text
Logo | Blog                         ⋮
```

Clicking the three dots displays the available blog domains.

## 🎯 Project Purpose

The main purpose of this project is to practice building a **responsive blog interface using React.js**, while learning component-based development, React Router, reusable components, state management, and responsive CSS.

---

## 📚 What I Learned

Through this project, I practiced:

* ⚛️ Creating reusable React components
* 🧩 Passing props between components
* 🔄 Using React state with `useState`
* 🔗 Navigation using React Router
* 📍 Using `useLocation` for active navigation
* 🔢 Rendering dynamic content using `.map()`
* 🔎 Filtering data using `.filter()`
* 📱 Creating responsive layouts with CSS media queries
* 📌 Creating sticky headers
* 🎨 Building a clean and responsive UI
* 🚀 Deploying a React application using Netlify
